# 来源、适配与边界

更新：2026-10-20。项目提供研究与写作指导，非 CVPR、IEEE/CVF、Nature 或 OpenAI 官方产品。

## 阅读项目

早期指导来自 CVPR 2024–2026 论文阅读项目中的选择性案例。原目标清单没有全量读完，样本不是随机抽样；本项目不能据此报告三年总体规律、录用因果关系或预测准确率。公开案例保留在 [evidence.md](evidence.md)，历史阅读定位与本次复核范围分开。

仓库不含论文全文、原始图像、内部阅读数据库、私有实验和服务器路径。案例是简短分析，不替代原文；后续引用具体数字或进行批评时重新核验。

## 参考 Nature 系列技能的设计思想

参考本地已有 nature-writing、nature-polishing、nature-reviewer、nature-response、nature-figure、nature-citation 与 nature-data 的能力组织，针对 CV/ML 作者工作流重新编写。没有打包这些技能原文、文章库、脚本或第三方图片，不要求安装它们。

| 借鉴方向 | 在本项目中的适配 |
|---|---|
| 论点与证据先行 | 中心命题及 claim–evidence 表 |
| 术语稳定、段落有功能 | 局部修改与跨章节一致性 |
| 基于共享事实的不同评审重点 | 可选模拟视角，不伪装独立评审 |
| 回复可追踪到实际修改 | 意见 ID、证据、状态和未解决项 |
| 图先定义科学任务 | 图表职责、对照、单位及视觉检查 |
| 引用与数据来源可追踪 | 主张到来源、实际代码数据可用性 |

不迁移：Nature 期刊的重要性门槛、只搜 CNS 文献、期刊修回流程、固定三份审稿报告、强制每步确认，以及与任务无关的功能。未确认的本地技能作者身份和上游许可不编造成可公开复用授权；本仓库采用独立措辞实现上述工作流思想。

## 官方规则与实现建议分开

- [CVPR 2026 Reviewer Guidelines](https://cvpr.thecvf.com/Conferences/2026/ReviewerGuidelines)：贡献评价及正式审稿的使用边界。
- [CVPR 2026 Author Guidelines](https://cvpr.thecvf.com/Conferences/2026/AuthorGuidelines)：作者对提交内容负责；格式、回复等约束需要按年份核验。
- [CVPR 2027 Call for Papers](https://cvpr.thecvf.com/Conferences/2027/CallForPapers)：本次核查时 LLM 具体范围仍在制定，不能由此推断任意正式审稿使用均获许可。
- [OpenAI skill 文档](https://learn.chatgpt.com/docs/build-skills)：技能目录、元信息与按需加载。安装路径应结合宿主版本；本项目允许指定目录。

四档预审倾向、六维检查、问题严重度、模板和修复优先级均为项目设计，不冒充官方评分表。网页规则会变化，实际投稿或受托审稿时重新核验。

## 已验证与未验证

结构/链接/安装测试可验证包的可用性，不证明语言模型判断一定正确。2026-10-20另完成三篇正式论文主文与关键渲染页复核，范围见 [案例](evidence.md)，据此澄清章节自由度、消融边界与图表协议。

一次独立代理的合成回归检查能识别该案例中的归因、预算、泛化和精选图问题；它接近既有示例，不是新分布或真实录用结果的校准。尚未提供真实论文的盲测评估、无skill对照或预测准确率；不得宣传为通过率工具。公开仓库docs目录保留详细验证记录。
