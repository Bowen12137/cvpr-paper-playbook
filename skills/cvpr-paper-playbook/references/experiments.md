# Experimental Design：让每个实验有明确证明责任

## 从主张选择实验

| 主张 | 优先证据 | 不能替代它的证据 |
|---|---|---|
| 比现有方法更有效 | 合理强基线、统一协议、效应量和成本 | 只有弱基线或精选案例 |
| 收益来自某机制 | 控制其他变量的消融/替代机制比较 | 多模块、数据和模型规模同时改变 |
| 对新条件泛化 | 定义训练与测试差异、隔离单位、留出测试 | 分别训练在多个数据集上 |
| 数据有新价值 | 标注质量、分布覆盖、能揭示或支持的新研究问题 | 样本数量和好看样例 |
| 生成结果可用 | 有效性、条件遵循、下游成功和失败分母 | 单参考距离、渲染美观 |
| 编辑保留原内容 | 目标改变与非目标保持分别评价 | 只展示目标属性出现 |
| 更快/更省 | 同质量或质量—成本曲线，明确计时边界 | 不同硬件或只算部分流水线 |
| 真实世界有效 | 与主张匹配的真实数据或物理任务验证 | 把合成模拟或动画称为物理实证 |

## Baseline 公平性

先找最接近的替代解释，而非最容易赢的方法。核对输入信息、预训练数据、额外监督、参数量/计算量、测试时优化、调参预算、后处理和评估子集。

信息或资源不等价的比较仍可有价值，但应作为完整系统比较；另设控制实验支撑具体模块归因。新任务没有天然基线时，说明适配链、损失了什么信息，尽可能给基线合理适配；不要把适配链的全部失败算作核心技术优势。

将只看训练集、使用目标测试序列拟合、先看完整序列再回看三种设置分开。后两者可证明拟合或重建能力，不能直接支持首次在线或未见运动泛化。

## Ablation

先写“去掉/替换X后，预期哪种失败增加，为什么”。据此选择最小且有判别力的比较。

- 去模块：检验是否有用。
- 等成本替代：检验是否是提出的机制，而非更多参数/计算。
- 强度或规模曲线：检验效应是否随假设变量变化。
- 交互消融：仅在多个机制的耦合是中心主张时需要，不强求全因子表。

某项消融没变差不必隐藏：可能说明设计非必要、指标不敏感或只在某子条件起作用。结论要跟着证据调整。

## OOD 与真实实验

仅在主张需要时设计OOD。明确变化轴：对象/身份、场景、任务、传感器、材质、动作、数据来源或尺度；按可能泄漏的单位切分，例如人、衣物设计家族、base/edit对、序列或场景，而非只随机分帧。

“真实”应写具体：真实照片、真实扫描、真实物体静态测试、闭环动作或制造验证。与研究目的匹配即可，不要求每篇都做机器人实物实验；也不把更弱层面的结果说成更强层面的成功。

## 分母、指标与不确定性

先声明评价对象、条件和独立单位。顶点数、视频帧数、多个增强视图不能自动当作独立样本。只在有效预测上计算的误差，应与失败率/覆盖率并列；组合结构准确率不是整任务成功率。

区分绝对差与相对提升，区分距离与平方距离，区分每样本平均与全体点平均。同一结果可能某指标改善、另一指标退步，解释权衡。

根据效应大小、随机性和决策风险建议多seed、配对比较、按人/场景聚类的区间或重复实测。不要机械要求所有理论或确定性算法都有多seed；也不凭均值宣称统计显著。

## 给用户的最小实验矩阵

每行包括：要支持的主张｜竞争解释｜控制变量｜实验/评价单位｜指标｜成功与失败如何解读。按“最可能推翻中心故事”和“实施成本”排序，先做能决定路线的实验，再扩覆盖和美化主表。

Reviewer快速检查：最强主张是否有直接证据？公平性条件是否可见？消融能否排除简单替代解释？泛化是否真留出？失败样本是否被计入？论文是否将适用边界说清楚？只把实质缺口列为优先行动。
