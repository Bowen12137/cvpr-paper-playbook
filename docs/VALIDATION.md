## 自动检查

- 本仓库限制格式的 name/description 与 UI 元数据检查。
- Markdown 本地文件链接、私有绝对路径及未完成脚手架检查。
- 安装五项测试：完整复制、已有修改拒绝覆盖、备份后升级、拒绝覆盖符号链接、写入失败回滚。

安装器只需 Python 3.9+；CI 固定 Python 3.11。元数据检查器是本项目的简易格式检查，不是完整 YAML 或官方 skill validator。外部 URL 可达性和文献逐句支持不在自动检查范围。

## 发布边界

公开包只包含总版 skill、模板、示例和检查脚本；不含内部论文库、原文 PDF、截图、受托审稿、私人配置或账号凭据。许可证不覆盖外部文献。
