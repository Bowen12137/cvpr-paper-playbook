# Contributing

请提供可公开的输入例子、实际输出问题、预期改进及适用范围。不要提交保密稿件、审稿意见、账户信息、私有路径或未获授权的数据。

修改对应 reference，保持 SKILL.md 简洁。规则应改变实际决策；单个失败样本不足以支持一条适用于所有论文的禁令。官方政策须附链接、年份和核验日期，项目建议不能冒充官方要求。

涉及引文时核对原始来源，区分作者主张与本项目解释。避免大段复制论文或其他 skill；需要复用第三方材料先确认许可并保留归属。

提交前运行结构检查和安装测试，新增对应行为案例。模型运行结果须记录模型/日期/输入/范围；未执行就标未执行。不要把文档存在、CI 通过或少量示例称为录用预测验证。
